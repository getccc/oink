## Linkit：免费开源的桌面书签管理器

- **免费内容**：Linkit 采用 MIT 许可证，支持本地存储，可导入 Chrome、Edge、Firefox 和 Safari 的书签，也提供死链检测和重复书签整理。
- **下载条件**：项目发布页提供 Windows、macOS 和 Linux 安装包。只想整理书签，可以先用本地功能。
- **AI 使用条件**：自动摘要和语义搜索等 AI 功能需要自行配置兼容的 API 或本地模型（如 Ollama）。软件免费不等于第三方 API 免费，费用以模型服务商为准。
- **截止时间**：未公布领取期限；这是常设开源资源，不是限时优惠。
